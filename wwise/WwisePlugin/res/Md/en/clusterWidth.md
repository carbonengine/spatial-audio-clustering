## Cluster Width

Largest angle, as heard from the listener, between an input and a cluster for the input to join that cluster. A larger angle merges more inputs into fewer outputs. A smaller angle keeps more spatial detail.

At 0, inputs are not merged by angle. They merge only when the Object Limit requires it.

**Note**: With Distance Sensitivity above 0, a difference in distance from the listener is added to the angle before it is compared with the Cluster Width.

Units: degrees
